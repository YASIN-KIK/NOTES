# Notes App (Desktop)

## Features
- Notes with folders, tags, pin, favorites, trash + restore
- Markdown editor with live preview and checklists
- Reminders with native Windows notifications
- Note encryption (password-protect individual notes)
- App lock (password on launch)
- Voice input (speech-to-text)
- AI writing assistant (OpenAI / compatible APIs)
- Command palette (Ctrl+K) and keyboard shortcuts
- System tray, launch at startup, global hotkey (Ctrl+Shift+N)
- Optional sign-up + admin dashboard
- Cloud sync (register/login, push/pull, auto-sync)
- Real-time collaboration (share a note, join by code)
- PWA (installable web build for mobile/desktop browser)
- Auto-update (when published)
- Export/import backups, print
- **Story Writer mode** — chapters, characters, outline, focus mode, word counts
- **Secret Diary mode** — password-protected, moon/night theme, mood tracking
- **Code Editor mode** — CodeMirror with JS/Python/HTML/CSS/Markdown, run JS, output panel

A simple, cross-platform notes app built with **Electron + React + TypeScript**.
Notes are stored locally (localStorage) and persist between sessions.

## Run in development

```bash
npm install
npm run dev
```

This starts the Vite dev server and launches Electron.

## Build

```bash
npm run build          # type-check + build renderer
npm run electron:build  # package the app
```

Output goes to `release/`:
- `Notes Setup 1.0.0.exe` — installer (per-user, no admin needed)
- `win-unpacked/Notes.exe` — runnable unpacked app
- `Notes 1.0.0.appx` — Microsoft Store package, only from `npm run electron:build:store`

## Publish to the Microsoft Store (optional, costs ~$19 once)

1. Create a Microsoft Partner Center account and reserve an app name.
2. Open **Apps and games → your app → Product identity** and copy three values:
   - **Package/Identity/Name** (looks like `12345YourName.NotesApp`)
   - **Package/Properties/Publisher** (starts with `CN=`)
   - **Publisher display name**

   Write them into `package.json` with the helper script:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/set-identity.ps1 `
     -IdentityName "12345YourName.NotesApp" `
     -Publisher "CN=1A2B3C4D-0000-0000-0000-000000000000" `
     -DisplayName "Your Name"
   ```

   Check the current values at any time with `-Show`.
3. Icons are generated by `scripts/make-icons.ps1`:
   - `build/icon.png` (512×512) — desktop/exe icon
   - `build/appx/*.png` — Store tile logos (StoreLogo, Square44x44, Square150x150, Wide310x150)

   Re-run the script after editing the design, then rebuild.
4. For Store submission you need a signed package. Electron-builder signs with a
   certificate; either:
   - Use a code-signing certificate (`.pfx`) and set `win.certificateFile` /
     `win.certificatePassword` (or env vars `CSC_LINK` / `CSC_KEY_PASSWORD`), or
   - Submit unsigned and let Partner Center sign (Store can sign for you if you
     enable "Microsoft manages signing" — recommended for beginners).
5. Upload the `.appx` to Partner Center → Packages, fill in store listing, submit.
6. Ensure `version` in `package.json` matches the version you reserve.

> The `.appx` build needs about 2 GB of free RAM. Close the app and any dev
> server before running `npm run electron:build:store`, otherwise `makeappx` can
> fail with `0x8007000e - Not enough memory resources`.

## AI Assistant
The editor includes an **🤖 AI** button. It works with OpenAI or any OpenAI-compatible API (Azure, LM Studio, Ollama). Open Settings (⚙) to set:
- Base URL (default `https://api.openai.com/v1`)
- API key
- Model (default `gpt-4o-mini`)

Quick actions: Write, Expand, Summarize, Fix grammar, Continue, Translate EN. Results can be appended or replace the note. Keys are stored locally.

## Backend (optional sign-up / admin dashboard / cloud sync / collaboration)
The `server/` folder runs a Node/Express backend that provides:
- Sign-up / login and a full web **admin dashboard** at `/admin`
- Cloud sync (push/pull notes) for cross-device sync
- Real-time collaboration via Socket.IO (shared note rooms)

### Run locally
```bash
cd server
npm install
$env:ADMIN_PASSWORD = "choose-a-strong-password"   # PowerShell
npm start            # http://localhost:3000  →  admin at /admin
```

### Admin dashboard (`/admin`)
Sign in with `ADMIN_PASSWORD`. The dashboard shows:
- **Stats:** users, notes stored, folders stored, skipped signups
- **Users tab:** search users, see email/device/note count, open their notes, see **Details** (full user record + every note they wrote + folders), delete a user
- **Notes tab:** pick a user, search their synced notes, view full text, delete a note
- **Details view:** reads everything the user wrote, shows all their folders, and can download that user's full data as JSON
- **My notes tab:** the admin can write, save, edit and delete their own notes — just like a normal user
- **Skips tab:** see everyone who skipped signup
- **Export data:** downloads the whole `data.json` as a backup
- **Refresh / Sign out**

### Deploy for free
Deploy `server/` to a free host (Render / Railway / Fly.io), set `ADMIN_PASSWORD` in the host's environment variables, then paste the server URL into the app's **Settings → Backend URL**. The admin dashboard is at `<your-server-url>/admin`.

> Keep the admin password secret. Anyone with it can view and delete users and notes.

## Full publish checklist (Microsoft Store)
1. Set the identity values with `scripts/set-identity.ps1` (Partner Center → Product identity).
2. Set `author` and `description` (author is already `Yasin Kik`).

9. Upload the `.appx` to Partner Center → Packages, fill in the store listing, submit.

## Live collaboration (free, no server to run)
- Click the 🤝 **Live** button (or ⋯ → Collaborate live).
- **Sign up** with a name, email and password on your device. Accounts are stored locally.
- **Host:** open a note → ⋯ → **Share this note live** → **Start sharing this note**. You get a 6-character code and an invite link (`notes://join/CODE`). Send either to a friend.
- **Join:** enter the code, or click the invite link on a PC with Notes installed — the app opens the session automatically. The host's note is copied into your notes list.
- Everyone edits **that same note**: title and text changes appear live on both devices and are saved into the note.
- Roles: the host is the **👑 Boss** — can add people (invite link), remove assistants (✕ beside their name), and delete the note for everyone. People who join are **Assistants** — they can edit the note but cannot add/remove people or delete it.
- Sync uses a free public MQTT relay (`wss://broker.emqx.io:8084/mqtt`) — no account, no payment, no server to host. Don't use it for sensitive information.
