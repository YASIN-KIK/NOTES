Notes

## Short description (max 200 chars)
A simple, fast notes app. Folders, tags, markdown, dark mode, and an optional AI writing assistant. Your notes stay on your device.

## Description
Notes is a clean, offline-first notes app for Windows.

Features:
- Create, edit, search, and organize notes
- Folders and tags
- Markdown support with live preview
- Pin and favorite notes
- Trash with restore
- Dark and light themes
- Adjustable font size
- Export notes as Markdown or full JSON backup
- Optional AI writing assistant (bring your own API key)
- Optional account (skippable) — app works fully offline

Your notes are stored locally on your device. No note content is ever sent to a server unless you use the optional AI Assistant with your own API key.
